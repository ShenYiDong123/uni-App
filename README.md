# YD-APP

> 基于 uni-app 框架开发的跨平台电商移动应用

## 📱 项目简介

YD-APP 是一款使用 uni-app 框架开发的跨平台电商应用，支持编译到iOS、Android、H5、以及各种小程序平台。应用采用Vue 3技术栈，提供完整的购物体验功能。

## ✨ 功能特性

- 🏠 **首页模块**
  - 搜索功能
  - 轮播图展示
  - 商品分类导航
  - 热门商品推荐列表

- 🛒 **购物车模块**
  - 商品购物车管理
  - 商品数量调整
  - 价格计算

- 💬 **消息模块**
  - 系统消息通知
  - 订单状态提醒

- 👤 **个人中心**
  - 用户信息管理
  - 订单查看
  - 设置功能

## 🛠️ 技术栈

- **框架**: uni-app
- **前端**: Vue 3
- **样式**: SCSS + CSS
- **图标**: iconfont
- **开发工具**: HBuilderX

## 📦 项目结构

```
uni-App/
├── components/          # 组件目录
│   ├── banner/         # 轮播图组件
│   ├── category/       # 分类组件
│   ├── list/           # 列表组件
│   ├── search/         # 搜索组件
│   └── shopping/       # 购物车组件
├── pages/              # 页面目录
│   ├── index/          # 首页
│   ├── shopping/       # 购物车页面
│   ├── msg/            # 消息页面
│   └── my/             # 个人中心页面
├── static/             # 静态资源
│   ├── icon/           # 图标资源
│   └── tab/            # 底部导航图标
├── App.vue             # 应用入口文件
├── main.js             # 主入口文件
├── pages.json          # 页面路由配置
├── manifest.json       # 应用配置文件
└── uni.scss           # 全局样式
```

## 🚀 快速开始

### 环境要求

- HBuilderX 3.0+
- Node.js 14+

### 安装步骤

1. **克隆项目**
   ```bash
   git clone [项目地址]
   cd uni-App
   ```

2. **使用HBuilderX打开项目**
   - 打开 HBuilderX
   - 文件 → 打开目录 → 选择项目文件夹

3. **运行项目**
   - 点击工具栏的"运行"按钮
   - 选择运行到浏览器、模拟器或真机

### 编译发布

- **H5发布**: 运行 → 发行 → 网站-H5手机版
- **小程序发布**: 运行 → 发行 → 小程序-微信
- **App发布**: 运行 → 发行 → App-云打包

## 🔧 开发说明

### 组件开发
项目采用组件化开发模式，所有可复用的UI组件都放在 `components` 目录下。

### 样式规范
- 使用 rpx 作为尺寸单位，确保多端适配
- 全局样式定义在 `uni.scss` 文件中
- 引入了 iconfont 图标库

### 路由配置
页面路由在 `pages.json` 中统一配置，支持导航栏自定义和底部Tab栏。
